# PERFECT 다트 토너먼트 홈페이지 리뉴얼 기획서

현재 일본어로 제공되는 PERFECT 다트 프로 토너먼트 홈페이지를 한국어로 번역하고, 메인 화면의 UI/UX와 콘텐츠 배치 순서를 현대적이고 역동적인 스타일로 재정의하는 리뉴얼 계획입니다. 핵심 기능(대회 정보, 랭킹, 뉴스 등)은 그대로 유지하되, 사용자 시선 흐름에 맞게 레이아웃을 개편합니다.

## User Review Required

> [!IMPORTANT]
> **콘텐츠 배치 순서 및 UI 콘셉트 승인 요청**
> 아래 제안된 메인 페이지의 새로운 콘텐츠 레이아웃(섹션 순서)과 UI 테마(다크 모드 또는 모던 스포츠 테마)에 대해 확인 및 피드백 부탁드립니다. 확정해주시면 해당 기획을 바탕으로 메인 페이지 퍼블리싱(개발)을 시작하겠습니다.

## 확정된 디자인 컨셉 및 가이드

> [!NOTE]
> **디자인 방향성 확정**
> 1. **테마**: 라이트 버전의 깨끗한(Clean) 스타일. (제공된 골프 레퍼런스 사이트의 UI 레이아웃/스타일 차용)
> 2. **UI 디테일**: 
>    - 카드나 배너의 둥근 모서리는 기본 8px, 최대 16px을 넘지 않음. 
>    - 선수/랭킹 카드의 경우 레퍼런스처럼 이미지가 꽉 차고 하단에 그라데이션과 텍스트가 얹어지는 깔끔한 스타일 활용.
>    - 섹션 제목은 좌측 정렬의 굵은 텍스트, 우측에는 '전체보기' 텍스트 버튼 배치.
> 3. **메인 배경색(BG)**: Gray-100 (`#E8E8E8`) 또는 White 등 섹션별 대비 활용.
> 4. **폰트(Typography)**: 모든 폰트는 'Pretendard' 사용. 폰트 위계는 제공된 '피닉스다트 타이포그래피' 기준 준수.
> 5. **컬러 시스템**: 제공된 '피닉스다트 컬러 시스템' (Primary Red, Gray scale, Secondary 등)을 엄격히 적용.
> 6. **프레임워크**: 기존 프로젝트(`phoenixdarts_prodarts`)의 Next.js 및 Tailwind CSS 환경에서 진행.

## Proposed Changes

메인 페이지(`src/app/page.tsx` 예상)의 레이아웃을 사용자 경험(UX) 중심으로 아래 순서에 맞게 재배치 및 개발합니다.

### 1. 메인 키비주얼 (Main Key Visual) & 네비게이션
- **GNB (글로벌 네비게이션)**: PERFECT 소개, 투어 일정, LIVE 중계, 대회 결과, 랭킹, 선수 명단 등 한국어 번역 적용.
- **메인 배너**: 디졸브(Fade/Dissolve) 애니메이션 효과를 적용한 무한 스크롤링 스와이프(Carousel) 형태로 제작.

### 2. 다음 대회 목록 (NEXT PERFECT)
- 스와이프(Slider/Carousel) 형식으로 다가오는 대회 일정들을 한눈에 넘겨볼 수 있도록 구성.

### 3. 이벤트 띠배너 (Event Banner)
- 가로로 길게 배치되는 이벤트 배너. (높이 140px 고정)

### 4. 뉴스 (News)
- **탭(Tab) 목록**: 전체, 대회, 공지, 업데이트
- 깔끔한 리스트 형태의 UI를 제공하며, 각 탭에 맞게 필터링된 내용을 노출.

### 5. 랭킹 (Rankings)
- **탭(Tab) 목록**: 남자, 여자, 브랜드
- 각 탭 선택 시 1위부터 10위까지의 순위를 노출.

### 6. 미디어 (Media)
- 라이브 중계 영상 시청 및 관련 기사(Article) 링크 제공.

### 7. 스폰서 리스트 (Sponsor List)
- 대회 및 협회 스폰서 로고들의 리스트/그리드 뷰.

### 8. 푸터 (Footer)
- 개인정보처리방침, 문의하기, SNS 링크 및 패밀리 사이트 배너.
